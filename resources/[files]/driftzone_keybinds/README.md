# DriftZone Keybinds

- Nu foloseste RegisterKeyMapping.
- /keybind si /keybinds deschid meniul.
- Keybind-urile se salveaza in client KVP.
- UI-ul captureaza tasta cand apesi pe butonul key.
- ESC in modul "Apasa pe o tasta" abandoneaza schimbarea.
- RESET KEY reseteaza un singur keybind.
- RESET DEFAULT reseteaza toate keybind-urile.

Important: fara RegisterKeyMapping, FiveM poate detecta global doar taste care exista ca GTA controls. Daca o tasta nu merge, foloseste alta din config.lua.
