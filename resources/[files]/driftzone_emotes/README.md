# driftzone_emotes

Comenzi:
```txt
/emotes
/e nume
/e c
/ecancel
```

Am generat automat 394 emote-uri din lista ta de `.ycd`.

Copiaza folderul tau complet `stream` aici:

```txt
driftzone_emotes/stream/
```

Au fost adaugate in manifest 17 fisiere `.ytyp`.

Nu porni vechiul `rpemotes` in acelasi timp, pentru ca se bate pe `/e`.
